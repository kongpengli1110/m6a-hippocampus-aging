# Human pipeline entry point

Read the repository-level [README](../README.md) first. It contains installation, safe inspection, scratch-copy execution, stage order and explicit limitations.

- `python run.py --list`: list actual stage entrypoints.
- `python run.py <stage> --dry-run`: check without importing scientific code.
- `stages.json` / `stage_commands.tsv`: input/output DAG and exact commands.
- `input_manifest.json`: exact external data identities and required preparation.
- `claim_code_map.tsv`: manuscript-claim/statistical-code mapping.
- `provenance/source_map.json`: original source hashes, adaptation hashes/diffs and selected frozen inputs.
- `reference_outputs/`: selected historical references, **not outputs generated by this release**.
- `QA.json` / `audit/`: actual packaging tests, unresolved limitations and source/input audit.

No full scientific analysis was rerun during packaging. Do not execute old historical source under `provenance/original_scripts/` or alter frozen plans/candidates to bypass a failure. `excluded_legacy/` at repository root contains the unchanged invalid CCC script, not an analysis to run.
