## 3. 固定映射、输入尺度、actual expression与覆盖门槛

### 3.1 主映射与探针

使用已严格核验的HGNC/Entrez及SEA稳定Ensembl交叉表；不以大写mouse symbol推断同源。ARK2C/RNF165、QARS1等沿已核追溯关系。每集合只计不同稳定人类身份；本批1:1集合内已无重复，若后续技术文件出现多行指同一身份则停下核验，不能增加权重。

GSE只用**矩阵实际存在、可唯一归于一个稳定HGNC身份且无未解额外身份/冲突**的探针。每个探针先做下述变换，再按同一基因所有合格探针的中位数聚合，不按年龄相关性、方差最大、强度最高或显著性选探针。FBXO41的3个歧义探针主不纳，v1亦不做未经独立解决的“救回”敏感性。

已知技术覆盖：GSE core21/22、主程序113/120；SEA feature core22/22、主程序120/120。此处是平台存在，不是actual expression。

### 3.2 GSE尺度：透明的一次log2决定

本v1预设将series matrix作为GeneSpring归一化后的**正线性比值**，执行`log2(value)`一次，**不加1、不再quantile normalization、不重新每芯片/每基因归一化**。理由：官方描述per-chip 50th percentile/per-gene median，矩阵全正、median约0.887、min0.01、max1438.76，不应仅看到GC-RMA字样就当作最终已log2。

记录这是基于导出形态和处理文字的明确输入假设，而非已证实全部上游算法。进入代码时断言与preflight范围/校验值一致；遇非正/非有限值先核文件，不静默加伪计数。保存原值和变换标志防二次log2。仅一次预设的未log2比值敏感性，仍同探针/基因集合；不从两种尺度挑更显著者。如获得明确相反官方说明，应在看关联前修订版本，不暗改本计划。

GSE是经逐基因median归一化的微阵列比值，**CPM不适用，接近1不证明该基因实际表达**。没有原始检测调用时，不把比值阈值当present/absent；技术可用且跨参照样本非零方差即可计分，报告“缺乏独立实际检出门控”。不伪造微阵列actual-expression检出率。

### 3.3 SEA全基因库量与表达门控

对每个主阈值target参照群体R_t（所有技术合格≥20核供体，不按诊断/年龄分层）独立做：

1. `L_dt = sum(raw_UMI over all retained source features)`，不是候选矩阵列和；所有来源feature进入库总量，不因未映射HGNC而删库量。相同稳定gene的技术重复特征如经审核合并，只求和一次，保留记录。
2. `CPM_gdt = 1e6 * count_gdt / L_dt`，计分变换`x_gdt = log2(CPM_gdt + 1)`。v1固定普通CPM，不再试TMM、SCTransform或最优归一化。
3. actual-expression门槛：CPM≥1的供体数至少`max(5, ceil(0.20*|R_t|))`；按R_t全体计算，不用age/sex/诊断/认知分组，不使用DE/P值。CA3的29人对应至少6人，SUB31人对应至少7人。零count是有效生物/技术采样零，不视作缺失。
4. 全R_t上x有限且样本SD>1e-8才进入可评分基因视图；否则以独立原因标记未过门槛。此门控后固定集合，对不同模型完整病例、+Braak、认知及敏感性不得再次筛基因。

### 3.4 集合门槛与缺失分母

令G0为冻结集合的全部无歧义1:1人类基因（不是平台检出集合）；A为平台主映射、SEA表达门控（如适用）及参照方差过滤后保留的集合。对**所有集合/target**统一要求：

- `|A| >= max(10, ceil(0.80*|G0|))`；core至少18/22，主程序至少96/120。
- 模块额外要求`sum(kME_A)/sum(kME_G0) >= 0.80`；kME使用原精度，不四舍五入后判断。无权集合权重覆盖等于数量覆盖。
- 每集合逐步报告原始成员数、1:1数、技术覆盖数、actual-expression通过数、方差通过数、最终数量/权重覆盖及丢失ID。GSE actual-expression列填`not_assessable_from_ratio_matrix`，不能填21/22等注释率冒充表达率。
- 门槛失败：该集合×target标记`not_testable_coverage`，不补基因、不降低80%、不切换到≥0.6子集挽救主分析。主要检验位置保留，不能用另一target替代。
- 技术NA不填零；参照构建时有NA的gene整体移出A并重算覆盖。后续非参照样本（如新增阈值10供体、AD）若A中任一gene技术缺失，则该样本该score为NA；不作供体特异的可用基因均值或变化分母。所有样本的score分母始终相同。

## 4. 计分与标准化参照

GSE参照R为正常43个技术合格海马供体；SEA参照R_t为每target所有技术合格≥20核供体（无疾病/年龄筛选）。在各自参照中，按基因计算`mu_g=mean(x_g)`、`sd_g=sample_SD(x_g, ddof=1)`，`z_gd=(x_gd-mu_g)/sd_g`。不先对age/sex/Braak残差化，不在年轻人/无痴呆子集标准化，不根据结果决定方向。

- core及三程序：`S_d = sum(z_gd for g in A) / |A|`。
- 模块：`S_d = sum(kME_g*z_gd for g in A) / sum(kME_g for g in A)`。只用保留成员的**固定全样本分母**；排除成员不能当z=0留在分母。模块方向沿原正kME，不按人类beta翻号；不做人类PCA重估eigengene。
- 为统一效应单位，再用同一R计算`Y_d=(S_d-mean_R(S))/SD_R(S)`；若SD≤1e-8则不可检验。保存mu、sd、A、权重、S参照参数及校验值。报告原始mean-z得分和Y。
- 主年龄系数单位为“该固定参照score的SD/10岁”。认知使用相同Y作自变量，不能在认知完整病例中再标准化score。
- SEA不同target各自标准化，故均值不能直接证明细胞特异性；H2不能用这里的均值/回归代替。跨平台主分析用各自合格A，不强行交集；结果为同一定义集合的覆盖受限投射，不声称测量完全相同。
- 阈值10/30、+Braak、认知、疾病扩展均保留主参照及主A。≥0.6模块与跨平台交集敏感性只为其新子集计算一次相同R上的score尺度，不使用表型；不重新优化表达门槛。

## 5. 最小可执行模型及小样本边界

编码：`age10=(age_at_death-80)/10`（GSE用其年龄字段）；sex按Female=0/Male=1，未知性别不猜；`PMI_c=PMI_hours-mean_R(PMI)`、`RIN_c=RIN-mean_R(RIN)`。Braak由0/I/II/III/IV/V/VI映射0–6，作为一个线性有序项，不拆6个dummy；未能明确映射的值为缺失并报告。教育按years连续项，`education_years_centered=years_of_education-mean_R(years_of_education)`，R沿相应target主评分参照；不由学历类别猜年限。

所有线性模型用OLS、HC3异方差稳健协方差；每个目标系数使用`df=n-rank(X)`的双侧t检验和95% t CI。双侧alpha=0.05；H1/H3方向先验为负，正向即使显著也不算支持。所有实际效应/CI/P始终报告，不只列显著结果。CI为逐项而非多重同时区间，须标明。

### 主模型

- **P01 / H1**：GSE正常海马core `Y ~ 1 + age10 + sex`；检验age10。计划n43，参数p=3。
- **P02 / H3**：SEA CA3主程序 `Y ~ 1 + age10 + sex + PMI_c + RIN_c`；检验age10。预检n29，p=5，若全合格残差df=24。
- **P03 / H3**：SEA SUB同式，预检n31，p=5，残差df=26。

CA3/SUB的简约5参数模型在n29/31**可估计但不意味着高功效或无混杂**；不能因为低功效就把协变量逐步回归删掉。无年龄样条、无交互、无全协变量模型、无APOE/ADNC/Braak/诊断同时塞入主模型。年龄使用实际数值；如存在top coding必须先报告其规则，不推断被隐藏真实年龄。

### +Braak扩展（P02/P03各一次，不替换主分析）

`Y ~ 1 + age10 + sex + PMI_c + RIN_c + Braak_numeric`。CA3 n29时p=6、df=23，在代数上可估计；仅估计高龄病理谱内条件年龄关联，Braak可在年龄相关路径上，因此不是“排除AD影响后的因果年龄效应”。不以加Braak后显著与否定义主结果，不同时加入临床诊断。若Braak有缺失，主式在同一完整病例子集上同时重拟合作描述比较，不能把变化全归因于调整。

### 通用可估计性/诊断

每项模型先要求完整病例`n >= max(20, 3*p, p+15)`、设计矩阵满秩、年龄至少5个不同值且跨度≥10年（含年龄的模型），并且二元sex两水平都至少3人。不满足则`not_testable_design`；不自动简化救显著。主模型不因VIF/残差显著检验而改式。

执行时记录样本/模型流失、协变量范围、残差图、最大hat值、Cook距离及age VIF（只用设计矩阵计算）；age VIF≥10、hat>2p/n或Cook>4/n标记不稳定。不凭此删除供体；可作固定的leave-one-donor-out效应范围诊断，只报告beta范围/方向翻转数，不产生新的显著性判断或择优P值。设计秩不足或HC3无定义则不可检验。主结果宽CI/不稳定必须保留，不写“证明无效”。

## 6. 检验层级与多重校正

`prespecified_tests_v1.tsv`是一行一个基础检验、敏感性或延期登记，共62个唯一位置；敏感性家族按§8有限展开为S01–S23。阶段未到的检验不会自动运行。

### 唯一主要家族：P01–P03，共3项

建议使用**Holm FWER 0.05（m固定为3）**作主线支持门槛，适用于CA3/SUB供体重叠及集合相关，不假装独立；同时报告原始双侧P与Holm调整P。没有必要把H2、H4、认知、七模块全部塞入“主家族”。

- 单项支持：其age beta<0且Holm调整P<0.05。
- “CA3与SUB均支持程序随龄降低”：P02、P03均达上述标准；只有一个通过只表述对应target。两项均负但未过门槛称方向一致/证据不足，不称复制成功。
- 不能因P01没通过而删掉P01后以m=2重算；不可检验项公开显示NA及原因，校正算法内部用P=1保留该计划位置，不能称它已经被实际检验。
- 此门槛只指H1/H3年龄表达证据，**H2未完成时不能宣布主线A的人类“细胞富集”环节已完成**。

### 辅助/探索：BH FDR，各族内部固定m，q<0.05仍只作探索发现

1. `E_EXPR`，11项：GSE主程序1；SEA core在CA3/SUB/CA1/DG共4；主程序在CA1/DG共2；另外两程序在CA3/SUB共4。不得把CA1/DG最显著者换为H3主target。
2. `E_MODULE`，7项：每模块仅其同名SEA区域target的age模型（CA3-M2/M4→CA3；SUB-M4/M6→SUB；CA1-M9→CA1；DG-M3/M7→DG），全1:1成员、正kME加权。源小鼠七单模块P均>0.17，不能将模块描述为已确认的随龄下降证据；不预设所有方向为负。
3. `E_COG`，8项：core与主程序×CA3/SUB×MEM_E末访视与slope_zmem0。只在字典/时间QC放行后执行；无其它认知域、MMSE或临时组合终点。
4. `E_AD`，1项：GSE core的AD扩展。不是主年龄检验，不升级为年龄/疾病因果区分。

同一族不因缺失、低覆盖或不显著缩小m；不可执行位置内部P=1、公开NA。BH是在相关检验下的探索性FDR摘要，不承诺跨全部研究检验的全局错误率；主家族仍按Holm，不选最有利的校正。所有辅助族无论主检验是否显著均按相同规则报告，不能作为主要失败后的“救援证据”。

H2暂登记独立的未来富集家族，H4 conditional-later；不是本轮主要m的组成，也不把后续试验静默追加到已冻结v1。

### 末访视MEM_E：唯一主探索时窗为距死亡0–2年

- 用Donor ID精确连接；先按字段字典转换年月量纲。时间优先用官方精确assessment/death日期或MEM_E特定间隔；若只有已确认可相减的年龄，则`gap=Age_at_Death-age_vis`（年）。只有整数/舍入年龄但精度未说明时，不把差值当精确间隔，必须先澄清再放行。
